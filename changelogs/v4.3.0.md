## What's Changed

### New Features

- :sparkles: 新增无图形界面的命令行工具 `cctv-dl`，支持通过央视网 URL 浏览节目并下载指定条目，也可通过视频 GUID 直接下载。by @letr007
- :sparkles: `cctv-dl` 支持按月份列出节目、选择最新一期/全部/指定序号、包含节目看点，以及配置保存目录、下载线程、清晰度和 MP4 封装。by @letr007
- :sparkles: 新增 JSON Lines 输出、TTY 单行进度以及调试日志，便于在 SSH、容器及自动化脚本中使用。by @letr007

### Bug Fixes

- :bug: 修复新闻联播等新版栏目主页无法导入的问题，优先读取页面 `topicID`，并保留旧版 `/videoset` 页面 `lmtopId` 的兼容解析。by @letr007

### CI / Tests / Documentation

- :construction_worker: 将下载核心拆分为不依赖 Qt Widgets 的 `CCTVVideoDownloaderCore`，桌面应用和命令行工具复用同一套内容解析、下载、H5E 解密及 MP4 封装流程。by @letr007
- :construction_worker: 发布流程分别部署 GUI 与 CLI 依赖，并为三平台生成、校验和上传独立产物。by @letr007
- :white_check_mark: 测试拆分为核心回归、无头核心和 CLI 三组。by @letr007
- :memo: 精简项目首页并补充 `cctv-dl` 的常用命令、参数和源码构建说明。by @letr007

**Full Changelog**: https://github.com/letr007/CCTVVideoDownloader/compare/v4.2.1...v4.3.0
