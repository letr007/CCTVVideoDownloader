## What's Changed

### Breaking Changes

- :warning: 源码构建最低要求调整为 Qt 6.8，以支持系统深浅色主题检测，并与发布构建环境保持一致。

### New Features

- :sparkles: 重构桌面界面，统一 Windows、macOS、Linux 的布局、配色、控件状态与下载进度展示，并自动适配系统深浅色主题。by @letr007
- :sparkles: 将节目月份区间移至主窗口，按月栏目视频列表支持跨月、跨年请求；新增仅包含年份切换和 12 个月网格的月份选择器。by @letr007
- :sparkles: 根据 CCTV 页面特征选择内容解析策略，并支持通过旧版页面特征解析历史节目与视频。by @letr007
- :sparkles: macOS 发布新增引导式 DMG，Linux 发布新增 AppImage，同时保留原有便携压缩包。by @letr007

### Bug Fixes

- :bug: 修复两个节目区间输入框相互修改、未来月份导致区间失效，以及空列表缺少明确提示的问题。by @letr007
- :bug: 修复 TS → MP4 封装时间戳异常，以及下载合并阶段可能处理未成功解析分片的问题。by @letr007
- :bug: 修复应用标识、配置目录、日志目录和 macOS 应用图标在不同平台上的兼容性问题。by @letr007
- :bug: 修复导入取消、表格列宽、下载状态绘制，以及多个窗口的控件对齐、间距和尺寸限制问题。by @letr007

### CI / Tests / Documentation

- :construction_worker: 发布工作流现可生成 Windows ZIP、macOS ZIP/DMG、Linux tar.gz/AppImage 及统一 SHA256 校验文件。by @letr007
- :white_check_mark: 增加内容解析、下载合并、配置持久化、月份区间和月份选择器的回归覆盖。by @letr007
- :memo: 更新源码构建说明与 Qt 最低版本要求。by @letr007
