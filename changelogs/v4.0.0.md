## What's Changed

### Breaking Changes

- :warning: 解密与封装链路全面升级。移除旧版 `cbox.exe`、`decrypt` 目录及其运行时依赖，改用内置原生 H5E 解密和 libav 封装。发布包不再包含旧解密组件。
- :warning: 应用配置不再保存在程序启动目录的 `config/config.ini`，现保存到系统应用配置目录。升级后请重新确认下载目录、线程数、日期范围等设置；旧配置文件不会自动迁移。

### New Features

- :sparkles: 使用内置原生 H5E 解密实现处理 CCTV 加密视频，摆脱对外部 CBOX 程序的依赖。by @letr007
- :sparkles: 使用内置最小化 libav 在进程内完成 TS → MP4 封装，不再依赖外部 FFmpeg 可执行文件。by @letr007
- :sparkles: 新增 Windows x64、macOS arm64、Linux x86_64 发布包，并完善对应平台的构建、测试与运行时依赖部署。by @letr007
- :sparkles: 关于窗口现在显示当前构建版本。by @letr007

### Bug Fixes

- :bug: 修复 macOS 退出应用时可能发生的崩溃。by @letr007
- :bug: 修复 Windows 下 FFmpeg 构建、MSVC 静态库链接及运行时依赖部署问题。by @letr007
- :bug: 修复 Linux 下 FFmpeg 构建环境与头文件大小写兼容性问题。by @letr007
- :bug: 下载和输出路径改用系统标准目录；默认下载目录不再硬编码。by @letr007
- :bug: 强化输出文件名兼容性，处理 Windows 非法字符、控制字符、保留设备名，以及末尾空格或句点。by @letr007
- :bug: 优先使用支持原生 H5E 解密的视频流。by @letr007
