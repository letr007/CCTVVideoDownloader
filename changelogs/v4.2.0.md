## What's Changed

### New Features

- :sparkles: 视频详情新增频道名称和视频时长，支持从列表数据即时展示，并在选中视频后异步补充媒体接口返回的信息。by @letr007
- :sparkles: 媒体质量选择改为读取 HLS Master Playlist 中的实际带宽、分辨率和变体地址，可适配不同频道和不同时期的视频流组合。by @letr007

### Bug Fixes

- :bug: 支持 CCTV-16 奥林匹克频道的 3000 码率 1080p 视频流；旧视频缺少该档位时会选择实际可用的最高质量。by @letr007
- :bug: 修复显式选择最高画质时可能忽略 4096000 带宽变体的问题，并保留 CCTV-4K 明文 4000 流的优先解析。by @letr007
- :bug: 修复明文 HLS 质量地址仅替换目录、未同步替换播放列表文件名的问题；新增 3000 码率探测并保留 URL 查询参数和片段标识。by @letr007
- :bug: 修复 macOS 发布包部署框架和资源后签名失效的问题；发布流程现会封装签名完整应用包并执行启动检查。by @letr007

### Tests

- :white_check_mark: 增加视频详情解析、异步请求竞态、CCTV-16/CCTV-4K 变体选择、旧视频质量回退和明文 HLS 地址生成的回归覆盖。by @letr007
